# وب‌سایت شخصی امیررضا بابالو — برند Arbu 🟣

سایت Next.js 16 با طراحی iOS (گلس‌مورفیسم)، صحنه سه‌بعدی Three.js و پالت برند آربو.

## اجرا روی سیستم خودت

پیش‌نیاز: **Node.js نسخه ۲۰ یا بالاتر** (یا Bun).

```bash
# ۱) نصب پکیج‌ها
npm install        # یا: bun install

# ۲) اجرای محیط توسعه
npm run dev        # یا: bun run dev
```

سپس در مرورگر باز کن: `http://localhost:3000`

## ساخت نسخه نهایی (Production)

```bash
npm run build
npm start
```

## ساختار پروژه

```
src/
├── app/
│   ├── layout.tsx        ← چیدمان اصلی (فارسی/RTL، متادیتا، فاوآیکون)
│   ├── globals.css       ← پالت رنگ برند، استایل‌های شیشه‌ای، فونت وزیرمتن
│   └── page.tsx          ← صفحه اصلی (ترکیب سکشن‌ها)
├── components/
│   ├── site/
│   │   ├── navbar.tsx    ← نوبار شیشه‌ای شناور + منوی موبایل
│   │   ├── hero.tsx      ← هیرو + کارت سه‌بعدی لوگو
│   │   ├── tilt-card.tsx ← کامپوننت تیلت سه‌بعدی با برق موس
│   │   ├── marquee.tsx   ← نوار متحرک
│   │   ├── brand.tsx     ← «آربو چیست؟» (ArbuiD / ArbuAX)
│   │   ├── journey.tsx   ← تایم‌لاین «مسیر من» + سیلوئت
│   │   ├── projects.tsx  ← سکشن تیره پروژه‌ها
│   │   ├── words.tsx     ← «حرف آخر» + امضا
│   │   ├── footer.tsx    ← فوتر تیره با لوگوی سفید
│   │   └── reveal.tsx    ← انیمیشن‌های اسکرول
│   └── three/
│       └── hero-scene.tsx ← صحنه سه‌بعدی Three.js (گوی بنفش، حلقه، ذرات)
└── public/
    ├── images/  ← لوگوی شفاف، لوگوی سفید، سیلوئت
    └── fonts/   ← وزیرمتن (۶ وزن)
```

## پالت رنگ برند

| رنگ | کد | کاربرد |
|---|---|---|
| سفید مایل به خاکستری | `#F2F1EE` | پس‌زمینه اصلی |
| مشکی | `#111111` | تیترها و سکشن‌های تیره |
| خاکستری تیره | `#454545` | متن‌های ثانویه |
| خاکستری روشن | `#D8D8D8` | جزئیات و بافت‌ها |
| بنفش الکتریکی | `#7200FF` | رنگ تأکیدی برند |
| بنفش روشن | `#A855F7` | گرادیان و افکت‌ها |

## نکته‌ها

- فونت‌ها و تصاویر **لوکال** هستن؛ بدون اینترنت هم لود می‌شن.
- صحنه سه‌بعدی روی موبایل به‌صورت خودکار سبک‌تر اجرا می‌شه.
- برای تغییر متن‌ها، فایل‌های پوشه `src/components/site/` رو ویرایش کن.
- لوگوی جدید؟ فقط فایل تصویر رو در `public/images/` جایگزین کن.
